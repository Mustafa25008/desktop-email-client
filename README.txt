# ✉️ Desktop Email Client (Gmail Clone)

A feature-rich desktop email client application built using C# .NET and Windows Forms, inspired by Gmail. This application allows users to securely send, receive, and manage emails with a user-friendly interface.

## ✨ Features

- **User Authentication:** Secure user registration and login system.
- **Email Composition:** Compose and send emails seamlessly.
- **Inbox Management:** View, organize, and manage incoming and sent messages.
- **Search & Filter:** Easily search and filter through emails.
- **Intuitive UI:** Clean and responsive Windows Forms interface.

---

## 🛠️ Technical Details

- **Language & Framework:** C# .NET Framework
- **Architecture:** Windows Forms (WinForms) Desktop Application
- **Core Libraries:** `System.Net.Mail` for email handling and networking
